Opportunity Center Edge Bridge 隐私政策

生效日期：2026-08-21　/　Effective date: 2026-08-21

本扩展在 Microsoft Edge 中连接用户本人设备上的 Opportunity Center 本地服务，用于展示已审核机会、执行低频账号会话状态检查，并在严格授权下准备数量为 1 的购物车。最终购买、付款、验证码和身份验证始终由用户本人完成。

处理的数据

扩展只处理完成上述功能所需的最小字段：扩展版本和配对状态、受审核的商家/商品标识、库存或账号会话的枚举状态、有限长度的原因码、时间戳、HTTP 状态、数量、价格上限及一次性命令标识。

不读取或保存的数据

扩展不读取、复制、记录、上传或出售密码、Cookie 值、浏览器密码管理器内容、地址、银行卡或付款资料、验证码、证件、网页截图、完整页面正文或普通浏览历史。

保存凭据登录

该能力默认关闭。仅当本机服务返回当前扩展、未到期授权和精确商家清单时，扩展才会在精确 HTTPS 官方登录表单上确认输入框是否由 Edge 自动填充，并最多提交一次。扩展不读取输入值；遇到 CAPTCHA、OTP、MFA、Windows Hello、域名不匹配或自动填充缺失时停止。

存储、传输与保留

数据保留在用户设备和本机回环地址 127.0.0.1。配对令牌只存于扩展会话存储；有限的幂等与状态回执存于扩展本地存储。扩展不向开发者服务器或广告网络发送这些数据，不包含远程代码。

权限用途

storage 用于本地状态和防重放；alarms 用于低频检查；tabs 用于精确页面交接；受限 host 权限仅用于清单中的本机回环与受审核商家。

删除与控制

用户可在 Edge 扩展管理页禁用或移除扩展，并可删除 Opportunity Center 本地数据。禁用本机授权会立即停止会话检查、自动填充提交和购物车准备。

English summary

The extension processes only typed local status and command fields required for reviewed opportunities, session checks, and quantity-one cart preparation. It does not read, copy, log, upload, or sell passwords, cookie values, payment data, addresses, verification codes, screenshots, full page content, or general browsing history. Data stays on the user's device and local loopback. Saved-credential login is off by default, uses only Edge autofill on exact approved HTTPS forms, and stops for CAPTCHA, MFA, OTP, Windows Hello, missing autofill, or domain mismatch. Contact: sbrrunner@gmail.com.
