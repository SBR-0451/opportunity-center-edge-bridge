# 闲鱼小众 TCG 实测分析（2026-11 普查）

## 结论

宝可梦、海贼王、万智牌、游戏王之外，闲鱼上**既有量、又有高端市场**的只有两款：**携战之境（UNION ARENA，以日版为主）**和**符文战场**。两者都有 2–4 万条在售，近 30 天上新约一半，前 60 条里就能看到万元以上的签名卡和奖品卡。

其中携战之境最突出：它在二线游戏里价格最高，前 60 条相关商品的中位价 400 元，有 8 条 ≥5000 元，最高一条是 18.88 万元的 RE0 声优直签金编卡。

往下一档：
- **体量大但偏中低价**：黑白双翼、数码宝贝、高达卡牌。
- **量小但有特点**：
  - 洛卡纳：总量只有六七千条，但大赛 PR 卡和评级卡的挂价能到 5–50 万。
  - 赤魂战纪（FaB）：量小，但上新快、单价高。
  - 影之诗进化对决：简中还在出新，BP20 刚开预售。
- **基本是死盘**：先导者、战斗之魂、Z/X、Lycee、Reバース、FFTCG、龙珠 Fusion World、星球大战无限、Altered、Force of Will、Sorcery。
- **hololive 卡牌**：在售三万多条，但近 30 天上新只有 10%，比预想冷得多。
- **国产卡**：小马宝莉、奥特曼、叶罗丽的在售量和一线相当（28–69 万条），但中位价只有 35–40 元，是另一个市场。国产新 TCG 里只有峡谷争锋、超英击战上新活跃；正面对决、一决三国几乎没人在卖。

## 数据来源与可信度

- **采集**：用户本人登录闲鱼后运行 `npm run survey`，时间是 2026-11-05 19:32–19:45 UTC。48 个关键词全部成功，未被风控拦截。
- **每个关键词的内容**：
  - 闲鱼返回的**搜索结果总数**（`numFound`）。
  - 默认排序下**前 2 页、60 条**商品的价格、发布时间、地区和标题。
  - 标题过滤后的"相关商品"统计。
- **四条使用限制**：
  1. **都是挂价，不是成交价。** 10 万元以上的挂单不少是"挂着不卖"或估价。
  2. **"想要"人数没采到。** 解析代码没找到这个字段，所有关键词都是 0，所以这一版没有需求侧数据，已在工具里修复。
  3. **总条数会被分词放大。** "高达卡牌""黑白双翼"这类泛关键词会匹配到很多不相关的商品，只有独特关键词的总条数比较可信。下表用 ✓ / ≈ / ✗ 标出。
  4. **前 60 条是默认排序（综合）的结果，不是随机抽样。** 它代表买家打开搜索时看到的东西，不代表全部在售商品。

## 值得用监控工具盯的

1. **携战之境 UA 日版高端单卡**：签名卡、金编卡、冠军奖品卡、PSA10 卡。它是二线里高端挂单最多的。建议关键词："union arena 签名""ua 金编""携战之境 冠军""union arena winner"，并给 RE0、命运石之门、进击的巨人这些热门 IP 单独设关键词。
2. **符文战场的奖品卡、签名卡和限量套装**：盯"符文战场 签名""符文战场 奖品""符文战场 限量"。普通异画卡已经跌到几十元，不值得盯。
3. **洛卡纳的大赛 PR 卡和评级卡**：总量小，但高价挂单集中，适合低频盯。注意 50 万这种挂价大概率不会成交。
4. **海贼王（一线）的奖品卡和编号礼盒卡**：量最大，错价机会也最多。
5. **超英击战的编号卡**：新游戏，量还小，可以早期观察。

**不建议盯的**：国产儿童收藏卡、先导者、战斗之魂、hololive，以及其他死盘游戏。

## 和上一版报告的差别

上一版只用了间接数据。下面这几处被实测数据推翻或修正：
- **海贼王**：应归一线，上一版放在二线是错的。实测在售 27–34 万条，和万智牌、游戏王同一量级。
- **携战之境 UA**：上一版只把它当作观察对象。实测它是二线里高端市场最深的，应升为二线 A。
- **hololive**：上一版建议重点监控。实测虽然在售三万多条，但近 30 天上新只有 10%，前 60 条最高价 500 元，降为冷门。
- **影之诗进化对决**：上一版写的是状态不明。实测简中出到第 20 弹，BP20 正在预售，游戏还活着。
- **国产新 TCG**：上一版根据官方赛事规模推测它们值得观察。实测正面对决、一决三国的二手市场几乎没起来，峡谷争锋和超英击战活跃。
- **洛卡纳**：上一版说国内偏冷。实测总量确实小，但大赛 PR 卡和评级卡有不少万元级挂单。
